# Muestra web estática

Demostración de diseño responsive para un negocio ficticio: LimpiaPro Express.

No representa una empresa real. No ofrece servicios, acepta pagos, recopila datos ni envía mensajes. El enlace de cotización solo conduce a una explicación dentro de la misma página.

El HTML y CSS son autocontenidos y no utilizan fotos, scripts ni recursos externos. La etiqueta DEMOSTRACIÓN aparece visible en la página.

Archivos públicos: `index.html`, `.nojekyll` y este `README.md`.
